# Nura — Project Overview

## One-paragraph summary

Nura is a mobile AI companion app designed exclusively for women. Unlike existing companion apps that target men or veer into romantic/sexual content, Nura offers a warm, intimate space where women can talk about anything — relationships, daily life, mental wellness, goals, or whatever's on their mind. The companion is powered by a large language model and enriched with agentic capabilities: it sends proactive notifications, follows up on past conversations, and acts as a genuine presence in the user's life, not just a passive chatbot.

---

## Goals

1. Give women a private, judgment-free AI companion they can talk to about anything
2. Make the companion feel proactive and present — it reaches out, not just responds
3. Ship a working MVP fast enough to get real user feedback before over-engineering
4. Build a foundation that is secure by design (conversations are sensitive personal data)
5. Keep the v1 free to lower the barrier to adoption during beta testing

---

## Launch markets & language

- **Launch market (MVP)**: French-speaking markets — lower barrier due to founder knowledge and network
- **Expansion**: English-speaking markets, then global — the product is built for this from day one
- **Language (MVP)**: French + English (UI and AI responses adapt to user's language preference)
- **Architecture note**: Nothing in the codebase should assume a specific geography. No hardcoded country lists, currency assumptions, or cultural references in code.

---

## Core user flow

```
1. App open → Splash / onboarding screen
2. Sign up / Log in (Supabase Auth — email or phone OTP)
3. Choose a companion persona (name, personality style)
4. Land on the Chat screen — start talking
5. AI responds in real time via OpenRouter (DeepSeek V4 primary, Minimax M2.5 fallback)
6. Over time: companion sends proactive notifications (Trigger.dev background jobs)
7. User can view conversation history, manage profile/settings
```

---

## Features (MVP scope)

### Authentication
- Email + password sign-up and login
- Phone number login (OTP)
- Password reset
- Session persistence

### Companion selection / onboarding
- User picks a companion persona (2–3 options: different names, tones)
- Short intro exchange to personalize the companion to the user
- Persona stored in user profile

### Chat
- Real-time streaming AI responses (OpenRouter → DeepSeek V4, fallback Minimax M2.5)
- Conversation history stored in Supabase
- Context window management (last N messages sent to AI)
- System prompt built from: companion persona + user profile summary + conversation history

### Agentic notifications (the differentiator)
- Trigger.dev background jobs scheduled per user
- Companion sends proactive push notifications (follow-ups, check-ins, reminders)
- Notification content generated by AI based on the user's recent conversations
- User can configure notification frequency in settings

### Profile & settings
- Display name, language preference (FR / EN)
- Companion personality selection (can be changed)
- Notification preferences (on/off, frequency)
- Account deletion (full data erasure, important for user trust)

---

## Out of scope — v1

- Romantic, sexual, or explicitly intimate content
- Payments and subscriptions (v1 is free beta)
- Voice messages or voice responses
- Group chats or social features
- Web version
- Real-time multi-user collaboration
- Versioned conversation history / export
- Enterprise or team plans

---

## Success criteria (MVP)

- A user can sign up, choose a companion, and have a real conversation within 2 minutes
- AI responses are coherent, contextual, and emotionally resonant
- At least one proactive notification is sent autonomously without user action
- App runs without crashes on iOS and Android (Expo)
- No API keys exposed in client code
- Conversations are private: User A cannot access User B's data
